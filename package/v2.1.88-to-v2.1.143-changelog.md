【三、新增全局选项 (+4)】

  1. --exclude-dynamic-system-prompt-sections
     将 per-machine 部分（cwd、env、memory paths、git status）从 system prompt
     移动到第一条 user message，提升跨用户 prompt-cache 复用率

  2. --plugin-url <url>
     从 URL 获取 .zip 插件（可重复指定）

  3. --remote-control [name]
     启动带 Remote Control 的交互式会话（可选命名）

  4. --remote-control-session-name-prefix <prefix>
     Remote Control 自动生成会话名的前缀（默认: hostname）

【四、修改描述/行为的选项 (+8)】

  1. --allowedTools / --disallowedTools
